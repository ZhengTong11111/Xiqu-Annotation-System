## 完整平台测试

先安装：

- Node.js 22+
- Docker Desktop
- 可选：FFmpeg，用于波形、频谱和 F0 分析

在项目根目录执行：

```
npm ci

docker compose up -d postgres
cp .env.example .env

npm run db:generate
npm run db:deploy
```

检查数据库是否正常：

```
docker compose ps
docker compose exec postgres pg_isready -U xiqu -d xiqu_platform
```

然后分别打开三个终端。

终端 1，启动 API：

```
npm run dev:api
```

终端 2，启动前端：

```
npm run dev:web
```

终端 3，需要波形、频谱、F0 时启动：

```
npm run dev:analysis-worker
```

打开：

```
http://localhost:5173/
```

开发环境 `.env` 默认启用了测试数据，首次启动 API 后会自动创建：

| 角色       | 账号      | 密码         |
| ---------- | --------- | ------------ |
| 超级管理员 | `admin`   | `admin123`   |
| 教师       | `ta`      | `ta123`      |
| 标注员     | `student` | `student123` |

这些账号只适用于本地开发，不能用于生产环境。

## 只测试本地标注工具

如果他只想导入本机 JSON、视频并测试时间轴，完全不需要数据库：

```
npm ci
npm run dev:web
```

打开登录页后选择“不登录，进入本地标注工具”。

## 数据保存在哪里

- PostgreSQL：Docker volume `xiqu-platform-postgres-data`
- 上传媒体与分析资产：`data/storage/`
- `.env`、数据库 volume 和 `data/` 都不会提交到 Git

停止服务但保留数据：

```
docker compose down
```

彻底删除本地数据库并重新初始化：

```
docker compose down -v
docker compose up -d postgres
npm run db:deploy
```

`down -v` 会永久删除他的本地数据库，只能在确认不需要数据时使用。

## 常见检查

API 存活：

```
curl http://127.0.0.1:4317/api/health/live
curl http://127.0.0.1:4317/api/health/ready
```

数据库启动失败：

```
docker compose logs postgres
```

波形分析不可用时，先确认 FFmpeg：

```
ffmpeg -version
```
