## gongchepu.net 的实际渲染模型

`gongchepu.net` 不是 Canvas 或 SVG 手绘，而是“GCN 文本解析 + DOM + CSS + 专用字体”：

- 页面通过 `new Reader($(".paper-container"), $("#gcn").text())` 把隐藏谱文交给 `GCNPaper`。
- `parseNotesString()` 按 `/(?=[^0-9\-\+])/` 把工尺谱内容切成音、板眼、腔格符号。
- `（...）` 不渲染可见括号，而是把其中的音设为 `side`，最终加 `.lyrics-side-note`，字号更小且向旁侧收。
- `/` 不渲染成普通斜杠，而是回写到前一个非零时长主音，给它加 `qikou` 符号。
- `h/s/d/c` 是独立的 `.gcn-s-huoqiang`、`.gcn-s-souqiang`、`.gcn-s-dieqiang`、`.gcn-s-cuoqiang` 字体 glyph。
- 每个音生成一个 `.lyrics-note`；音名 glyph 与 `.lyrics-beats` 内的板眼 glyph 同行。
- 整个工尺谱组 `.lyrics-notes` 先竖向堆叠，再统一 `rotate(-50deg) scaleY(0.93)`，不是为每个符号单独计算斜向坐标。
- 单字唱词原站尺寸为：`.lyrics` 高 `44px`，`.lyrics-text` 字号 `40px`，`.lyrics-notes` 位于 `left: 40px; top: 14px; font-size: 16px`。
- 原站用 `GCNSymbol-Kai` 字体把 class 映射成字形；精确复刻必须使用同一类字体映射。

## 编码基本形态

原始文本通常写作：

```text
字{工尺符号与附加标记}
```

例：

```text
那{六4（五）上+2s五36h}
```

大括号前的汉字对应父文字块；大括号内按时间顺序记录这个字上的工尺谱事件。一个工尺谱事件通常以一个工尺字开始，后面跟随数字、字母或其他符号，直到下一个工尺字出现。

当前解析假设与实现：

- 基本工尺字：`合 四 一 上 尺 工 凡 六 五 乙`。
- 工尺字后可带 `+` 或 `-`，在 gongchepu.net 中会换成高/低音区 glyph class，例如 `上+` → `gcn-s-shang-h`。
- `（五）` 这样的括号内工尺字仍然是一个音，但渲染为 side note，不显示括号。
- 工尺字后面的数字成为 `.lyrics-beats` 中的板眼 glyph。
- `/` 是 `qikou`，附着在前一个主音上，不开新斜列。

## 教材中可以确认的符号

以下内容来自 Excel/PDF，可作为较高置信度规则。

| 视觉符号 | 教学名称 | 含义 | 建议渲染 |
| --- | --- | --- | --- |
| 红色实点或短红画 | 头板 | 第一拍、强拍，随字或随腔而下 | 在对应工尺字旁绘制红色实点或短红笔画。 |
| 红色空心圈 | 中眼 | 中眼，可粗略理解为第三拍 | 在对应工尺字旁绘制红色空心圈。 |
| 黑色点 | 头末眼 | 头眼/末眼，可粗略理解为第二拍和第四拍 | 在对应工尺字旁绘制小黑点，位置区分头眼或末眼。 |
| 红色叉号 | 赠板 | 新的第一拍，依附原有板位扩充节奏 | 绘制红色叉号。 |
| 类 `IX` 符号 | 腰增板 | 腰部位置的赠板，新第一拍 | 在相邻工尺之间绘制紧凑的腰增板符号。 |
| 红色线条 | 底板 | 腔尽而下；散板中也可标句读 | 在句末或腔尾工尺旁绘制红色短线或斜线。 |
| 右下角 `L` 形 | 侧头末眼 | 延长一拍，位于两个工尺之间或旁侧 | 绘制黑色侧眼钩形或折线。 |
| 红色三角 | 侧中眼 | 加半拍；例如前音一拍半、后音半拍 | 在两个工尺之间绘制红色小三角。 |
| 小字、偏右工尺 | 时值减少 | 该音短于同拍内其他音 | 工尺字缩小并偏向后侧。 |
| 削角/切角符号 | 削角、气口 | 停顿、休止、可吸气处 | 绘制切角形或气口符号，保留为独立 mark。 |

PDF 中还强调：两个板眼符号之间的所有音符，全部属于前一个板眼。因此数字和符号不应在导入时直接换算为固定时值，必须结合相邻板眼、拍式和上下文解释。

## 数字编码的工作假设

下表是根据教学材料、`【忒忒令】` 截图和示例 JSON 对照得到的推断。置信度不是全部相同，后续还需要更多截图或原谱核验。

| 源码标记 | 推测含义 | 置信度 | 建议渲染 |
| --- | --- | --- | --- |
| `1` | 头板 | 高 | 红色实点或短红画，贴近前一个工尺字。 |
| `2` | 头眼 | 高 | 小黑点，作为第二拍位置。 |
| `3` | 中眼 | 高 | 红色空心圈。 |
| `4` | 末眼 | 中高 | 原站套红时为红色 glyph，作为第四拍/末眼位置。 |
| `5` | 底板 | 高 | 红色短线或斜线，常见于句末或腔尾，如 `尺5`、`合四5`。 |
| `6` | 侧头末眼 | 中高 | 黑色 L 形/折线侧眼，常与 `1/3/4` 连用表示延长，如 `六167`、`上36`、`五46`、`四3656`。 |
| `7` | 侧中眼 | 中 | 红色三角。常见于 `合276` 一类组合，符合教材中“侧中眼加半拍”的描述。 |

重要理解：数字不是简单“时长数字”，而是“附着在前一个工尺字上的板眼/侧眼/底板事件”。真正时值需要结合板式和相邻事件推导。

## 字母和其他符号的工作假设

| 源码标记 | 推测含义 | 置信度 | 建议渲染 |
| --- | --- | --- | --- |
| `+`，如 `上+` | 高音区/高音字形 | 中高 | 使用高音区工尺字形，或添加向上挑/亻旁类视觉处理。 |
| `-`，如 `工-` | 低音区/低音字形 | 中高 | 使用低音区工尺字形，或添加向下钩类视觉处理。 |
| `（...）` | 括注音、提示音、装饰性小音 | 中 | 小号、浅色或括注样式渲染；编辑时保留括号信息。 |
| `/` | 气口/qikou | 高 | 原站不直接显示斜杠，而是在前一个主音上加 `gcn-s-qikou`。 |
| `h` | 豁腔 | 高 | 教学表明确提到“尺和上之间的符号”为豁腔；渲染向上装饰音符号。 |
| `d` | 叠腔/点状重复音 | 高 | 在前一个工尺附近画小点；`dd` 可能画双点或加强的重复装饰。 |
| `s` | 擞腔 | 中高 | 渲染“捺/擞”类装饰符号；具体字形可能依来源变化。 |
| `c` | 削角/气口/断腔类符号 | 中低 | 暂按切角或气口符号渲染；需要更多图像确认它和掇腔/断腔的区别。 |

教学表还出现了“气口/断腔”和“掇腔”。在当前文本中，`/` 和 `c` 都可能承载这类信息，但二者的准确区分尚未完全确认。

## 与 `【忒忒令】` 示例的对照

### 例 1

```text
那{六4（五）上+2s五36h}
```

工作解析：

- `六4`：工尺 `六`，附 `4`，推测为末眼。
- `（五）`：括注工尺 `五`，作为提示音/装饰音处理。
- `上+2s`：高音区 `上`，附 `2` 头眼与 `s` 擞腔。
- `五36h`：工尺 `五`，附 `3` 中眼、`6` 侧头末眼、`h` 豁腔。

### 例 2

```text
石{工-1/合276四46合工-36/}
```

工作解析：

- `工-1`：低音区 `工`，附 `1` 头板。
- `/`：进入下一组。
- `合276`：`合`，附 `2` 头眼、`7` 侧中眼、`6` 侧头末眼。
- `四46`：`四`，附 `4` 末眼、`6` 侧头末眼。
- `合`：普通工尺音。
- `工-36`：低音区 `工`，附 `3` 中眼、`6` 侧头末眼。
- `/`：本组结束。

### 例 3

```text
錢{四3上2/（六d）}
```

工作解析：

- `四3`：`四` 附中眼。
- `上2`：`上` 附头眼。
- `/`：分组。
- `（六d）`：括注 `六`，附叠腔/点状重复音。括号和 `d` 都应保存，后续渲染中可表现为小号括注音旁的点。

## 后续渲染设计建议

先不要直接做整页古谱排版，建议在标注工具里分三层推进：

1. **数据层**：继续保留 `rawText`，不要丢失 `36h`、`276`、`（尺d）` 这类原始片段。
2. **解析层**：把 `notation` 再解析成结构化 `marks`，例如 `head-board`、`middle-eye`、`huo`、`sou`。
3. **渲染层**：优先复刻 gongchepu.net 的 DOM + CSS + 字体 glyph 结构；不要再用 SVG 近似手绘板眼与腔格。

建议未来数据结构：

```ts
type GongcheSymbol = {
  id: string;
  label: "合" | "四" | "上" | "尺" | "工" | "六" | "五" | string;
  register?: "low" | "middle" | "high";
  parenthesized?: boolean;
  rawText: string;
  notation: string;
  marks: Array<{
    kind:
      | "head-board"
      | "head-eye"
      | "middle-eye"
      | "end-eye"
      | "bottom-board"
      | "side-head-end-eye"
      | "side-middle-eye"
      | "added-board"
      | "waist-added-board"
      | "huo"
      | "die"
      | "sou"
      | "breath"
      | "unknown";
    source: string;
    confidence: number;
  }>;
  startTime: number;
  endTime: number;
};
```

## 渲染布局观察

截图里的排版是竖排歌词，工尺谱斜向悬挂在字旁。工具里可以先实现每个文字块的局部渲染：

- 父文字块显示大字。
- 工尺谱在字旁或块内以小号竖向堆叠，再整体旋转为斜列。
- `/` 不换列，作为 `qikou` 附着在前一个主音上。
- 板眼符号、腔格符号优先使用 `GCNSymbol-Kai` glyph，不用普通字符或 SVG 粗略模拟。
- 支持 debug 模式显示 `rawText`，便于校对。
