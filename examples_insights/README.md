# Examples And Insights

This folder stores real annotation examples and research notes used to evolve the Xiqu annotation workflow.

- `tutorial.md`: image-free Chinese tutorial for annotators using the deployed online platform.
- `央视_顾卫英《寻梦》.merged.cleaned.json`: existing aligned annotation example.
- `gongche_rendering_research.md`: current notes on Kunqu Gongche notation encoding and rendering strategy.
