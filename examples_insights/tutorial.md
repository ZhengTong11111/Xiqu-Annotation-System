# 在线标注员使用教程

## 1. 开始前准备

建议使用较新的 Chrome或Edge，并准备耳机和鼠标。触摸板也可以完成标注，但精细调整块边界时，
鼠标通常更稳定。

登录平台后会先进入资源管理器。开始标注前请确认：

- 打开的是老师或项目负责人指定的标注文件。
- 文件所关联的视频、音频和标注任务相互对应。
- 浏览器标签页没有被静音。
- 系统时间与网络连接正常。

不要同时在多个浏览器窗口中用同一账号编辑同一文件。平台能够识别同账号的多个窗口，但重复编辑会增加
判断当前修改来源的困难。

## 2. 找到并打开标注文件

资源管理器采用三栏结构：

- 左侧是项目导航、最近打开、收藏、归档和回收站等入口。
- 中间是当前目录中的项目、文件夹、标注文件和媒体文件。
- 右侧显示当前选中资源的基本信息。

推荐操作顺序：

1. 在左侧进入“所有项目”或“最近打开”。
2. 在中间打开指定项目和文件夹。
3. 双击标注 JSON 文件进入编辑器。
4. 等待文件、媒体和同步状态全部加载完成后再开始编辑。

可以使用资源管理器的搜索框按文件名查找资料。编辑完成后点击“返回资源管理器”，平台会回到这次打开文件
所在的目录，而不是强制返回根目录。

如果文件以只读状态打开，可以浏览、播放和检查内容，但不能提交修改。不要为此另建无关副本；请先确认自己
是否打开了正确文件，再联系项目负责人。

## 3. 认识编辑器

编辑器主要由以下区域组成：

- 顶部菜单栏：文件、编辑、播放、视图和帮助。
- 左上：视频播放器和监听音轨入口。
- 左下：多轨时间轴，是主要编辑区域。
- 右上：句级字幕列表。
- 右中：当前句逐字拆分。
- 右侧下方：标注审核和当前选中对象的属性面板。

右侧各区域可以调整高度。标注审核面板还可以通过“视图”菜单隐藏、恢复到右侧，或打开为独立窗口。视频和
时间轴也支持弹出窗口，适合双屏工作。若浏览器拦截弹窗，请允许当前站点打开弹窗后重试。

## 4. 检查视频和监听音轨

平台标注文件通常已经关联服务器媒体或阿里云 VOD。正常情况下，打开文件后视频会自动出现，不需要重新
上传或下载。

如果视频没有出现：

1. 等待几秒，确认不是临时加载。
2. 检查播放器中的错误提示并尝试“重试”。
3. 确认浏览器访问地址与平台要求一致，例如不要随意在 `localhost`、IP 地址和域名之间切换。
4. 仍然失败时记录文件名、时间和错误提示，交给项目负责人处理。

不要把 VOD 临时播放地址保存到项目文件中。平台会为每次播放自动取得短时会话。

### 切换监听音轨

如果项目给同一视频配置了原声、人声分离、伴奏或降噪音轨，可以使用播放器附近的“监听音轨”快速切换。
切换只改变实际听到的声音：

- 视频画面仍是唯一主时钟。
- 播放头和所有标注时间不会改变。
- 当前临时选择不进入撤销历史，也不会制造一次标注修改。
- 切换过程中出现“正在同步”属于正常状态。

如果一条音轨失效或暂时无法访问，播放器会暂停替换声音并提示重试，不会悄悄改播另一条声音。发现声音和
画面持续错位时，请先确认所选音轨，再向负责人报告，不要通过整体移动标注来掩盖媒体偏移问题。

当前版本中，“监听音轨”和“波形/频谱分析来源”是两个独立选择。切换听到的音轨后，如果还要查看该音轨的
波形、频谱或 F0，需要在“波形/频谱设置”中选择相同来源。

## 5. 推荐标注顺序

对一份新任务，建议按以下顺序工作：

1. 播放一小段视频，确认媒体、人物和时间轴对应。
2. 检查句级字幕的文字和起止时间。
3. 为每句选择“念白/唱”和角色行当。
4. 检查或创建逐字块，精修每个字的起止时间。
5. 按任务要求填写逐字四声。
6. 使用自定义腔格轨、动作轨或其他指定轨道完成专业标注。
7. 必要时开启波形、频谱、F0、板眼或工尺谱辅助检查。
8. 分段回放，检查遗漏、重叠和错位。
9. 确认顶部状态显示“已同步”后再离开文件。

先完成句级结构，再进行逐字和专业轨道标注，通常比在多个层级之间频繁跳转更不容易遗漏。

## 6. 播放和定位

### 常用播放操作

- 空格：播放或暂停。
- 播放菜单：前进或后退 0.1 秒。
- 播放菜单：前进或后退 1 帧。
- 播放速度：可在 `0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x` 之间选择。
- 点击时间尺或时间轴允许定位的位置：移动播放头。

点击标注块的主要作用是选中该块，不会仅因为选择文字块就把真实播放头移到块上。拖动块边界时，播放器会
显示边界对应的预览画面；预览时间和真实播放头是两个状态，松手提交后才完成本次边界修改。

### 缩放和滚动

- 横向缩小：查看较长时间范围和整体结构。
- 横向放大：精修逐字起止、动作边界和吸附位置。
- 纵向缩放：调整轨道高度，在“看清细节”和“同时查看更多轨道”之间切换。
- 横向滚动：移动到前后时间段，左侧轨道头会保持可见。

### 循环播放

循环范围适合反复听一句、一个字或一个动作：

1. 在循环区域拖出时间范围。
2. 拖动范围中间可整体移动，拖动两端可调整边界。
3. 按 `P` 从循环起点播放并进入循环。
4. 使用“播放 -> 清除循环选区”移除范围。

点击右侧句级字幕或时间轴顶部的句级块，会把循环范围更新为该句起止时间，适合逐句检查。

## 7. 标注句级字幕

句级字幕同时出现在右侧列表和时间轴顶部。每句需要填写：

- 发声方式：念白或唱。
- 角色行当：从当前项目角色列表中选择。

两项都填写后，句级字幕显示为蓝色；缺少任一项时显示为红色。红色表示该句分类尚未完成，不代表系统错误。

### 编辑方式

1. 点击右侧句子，切换当前工作句。
2. 在属性面板修改文字、开始时间、结束时间、发声方式和角色行当。
3. 也可以右键右侧句子或时间轴句级块，从菜单快速选择发声方式和角色。
4. 修改后检查当前句逐字拆分是否仍与句子对应。

如果任务需要新增或整理角色，可从“编辑 -> 句级标注设置”、句级右键菜单或逐字轨属性入口打开角色管理。
删除正在使用的角色时，系统会要求选择替代角色或明确清空相关句子，不能无提示地留下坏引用。

### 检查句级和逐字对应

使用“编辑 -> 检查句级/逐字文字轨”可以查找还没有逐字块的句子。对完全缺少逐字块的句子，工具可以先把
整句建立为一个文字块，之后再通过文字块右键菜单拆分。若检测到已有内容冲突，应先阅读提示并确认调整
范围，不要直接覆盖已经精修的逐字结果。

## 8. 标注逐字文字

选择句子后，右侧“当前句逐字拆分”会显示该句的文字块。逐字轨是字级时间和四声信息的主要载体。

### 创建和调整文字块

- 在逐字轨空白处按住 `Command`（macOS）或 `Ctrl`（Windows）拖拽，创建新块。
- 按任务界面支持的入口双击空白处，可尝试根据当前句创建或合并文字块。
- 拖动块中间，移动整个块。
- 拖动左边缘，修改开始时间。
- 拖动右边缘，修改结束时间。
- 需要精确数值时，在属性面板中输入时间。

逐字块可以通过右键菜单拆分，并可调整所属句子。拆分或重新归属后，应立即回放相邻字，检查是否出现漏字、
重复字或错误的句级关联。

### 四声信息

逐字属性支持《韵学骊珠》体例的阴阳八类：阴平、阳平、阴上、阳上、阴去、阳去、阴入、阳入。上声还可能
保留原书“阴阳通用”等细分信息。只在资料和任务要求允许时填写，不确定的字不要凭现代普通话声调猜测。

当前逐字格式已经不再保存“普通唱/拖腔”等旧唱法字段。具体腔格、拖腔或唱腔研究标签应记录在项目指定的
自定义轨道中，不要重新塞回逐字属性。

## 9. 动作轨和自定义轨道

动作、腔格、唱腔结构、眼神、走位、道具、姿态和其他研究维度通常使用自定义文字轨或自定义动作轨。

### 创建和编辑块

1. 找到任务指定的轨道。
2. 按住 `Command/Ctrl` 在空白处拖拽创建块。
3. 选中块，在右侧属性面板填写文字、类型或动作标签。
4. 拖动块或边界调整时间。
5. 回放前后内容，确认块的语义和时间一致。

不要因为一条轨道已有其他人的块就随意新建同义轨道。先确认项目的轨道命名和类型列表，保持同一项目的
标注口径一致。

### 分叉轨道

自定义文字轨和动作轨可以使用递归分叉。例如同一父轨记录“双手”，需要区分时再分为不同自定义名称的
子轨。分叉名称不固定为左右手，应按任务实际含义填写。

- 右键轨道头可以合并显示、展开展示或进入轨道设置。
- 右键块可以设置其分叉归属。
- 合并显示时，不同层级的块会按父轨、子轨顺序分层排列。
- 展开后每条可视轨独立显示，便于精细检查归属。
- 父轨块可以表示多个子分支共有的动作，子轨块表示该分支独有内容。

合并显示和展开展示会影响可见布局以及联合边界拖动范围。复杂修改前先确认当前显示模式，避免把本来只想
调整一个子轨块的操作应用到合并视图中的联合边界。

### 吸附和重叠

块边界可以吸附到同轨、父轨或同级子轨等可用参考边界。吸附提示只用于帮助对齐；松手后以最终提交结果为准。
轨道允许存在有意义的时间重叠，界面会自动纵向错层显示冲突块。时间首尾刚好相接不算重叠，不需要人为留缝。

## 10. 附属打点、工尺谱和板眼

这些轨道只在任务需要时使用。

### 附属打点轨

附属打点用于记录一个瞬间发生的事件，例如呼吸、重音、眼神切换、动作关键帧或锣鼓点。它依附在父轨道下，
可吸附到父块边界或波形关键位置。

### 工尺谱附属轨

一个文字块可以对应一个工尺谱块，一个工尺谱块可以包含多个符号。基本流程：

1. 选择逐字文字块。
2. 在属性面板的“工尺谱”区域创建或打开工尺谱块。
3. 使用快速输入修改简单工尺字，或用批量导入处理完整谱文。
4. 检查符号、附加信息和各符号起止时间。

批量导入会尝试把 `字{工尺内容}` 与当前文字模糊匹配，但不能替代人工校勘。导入后必须检查未匹配项、
错别字、念白和原谱分段差异。

### 板眼

板眼轨和全局板眼纵线默认关闭。需要时从“视图”中开启，并检查它们是否与当前工尺谱和时间范围对应。

## 11. 使用波形、频谱和 F0

音频波形、人声频谱、F0、板眼轨和板眼纵线默认关闭，需要时从“视图”或“波形/频谱设置”开启。

- 波形：帮助判断发声起止、重音和换气。
- 频谱：帮助观察唱腔与念白的频率结构。
- F0：辅助观察有声段的基频走向。
- `log` 或 `mel` 纵轴通常更适合观察唱腔。
- 50-2000 Hz 或 50-1500 Hz 预设适合聚焦人声区域。

平台分析由后台任务生成并按当前时间窗口逐步加载，不会一次把长视频下载到浏览器。快速滚动到较远位置时，
波形或频谱可能短暂分段出现；等待当前窗口加载即可，不必反复刷新页面。

如果显示“分析中”，可以继续播放和标注。若长时间没有结果：

1. 检查当前分析来源是否正确。
2. 检查任务状态和失败提示。
3. 尝试重新读取或重新分析。
4. 记录文件、音轨和错误信息，交给项目负责人排查。

## 12. 选择、复制和撤销

### 多选与剪贴板

- `Command/Ctrl + 点击`：增减多选。
- `Command/Ctrl + A`：选择时间轴中的可选项目。
- `Command/Ctrl + C`：复制。
- `Command/Ctrl + X`：剪切。
- `Command/Ctrl + V`：粘贴。
- `Delete` 或 `Backspace`：删除选中项。

粘贴前先点击或右键目标轨道位置，让系统知道目标轨道和时间。若目标已有块，系统会提示取消、覆盖、替换或
保留原内容。选择前应确认当前任务是否允许覆盖，特别是处理他人已完成标注时。

### 撤销与重做

- `Command/Ctrl + Z`：撤销。
- `Command/Ctrl + Shift + Z`：重做。

拖动操作通常在松手时形成一条历史记录，不会把拖动过程中的每一帧都写进撤销栈。结构编辑也支持撤销和
重做，但可能需要重新取得短时结构锁。

## 13. 保存、同步和多人协作

在线平台文件会在停止编辑约 3 秒后自动保存。顶部状态会分别反映实时连接、是否可编辑、结构编辑锁和保存
结果。完成一段工作后，应等待状态显示“已同步”再关闭页面或返回资源管理器。

常见状态含义：

- **已同步**：当前修改已进入服务器权威版本。
- **正在保存/同步中**：请等待，不要连续刷新。
- **结构编辑锁**：正在执行轨道、分叉、批量导入等结构操作。
- **离线或等待重试**：本地修改仍保留，恢复网络后会继续尝试。
- **同步失败/冲突**：不要反复编辑同一位置，先按界面提示检查和恢复。

平台还会把可写文件的恢复草稿保存在当前浏览器中。意外刷新后，系统可能提示恢复同 revision 草稿、比较
旧草稿和服务器版本、导出草稿或放弃草稿。看到提示时先阅读 revision 和操作数量，不要在未检查内容前直接
丢弃。

多人打开同一文件时，可以看到在线成员、远端播放头、鼠标时间和匿名选区范围。这些提示用于避免互相干扰，
不代表对方的临时操作已经保存。普通内容冲突会尽量自动追赶和重新提交；轨道结构、实体创建删除或复杂批量
操作无法证明安全时，平台会要求显式处理，不会静默覆盖其中一方。

建议多人协作时：

- 尽量分配不同时间段或不同轨道。
- 修改轨道结构前先与其他人沟通。
- 看到远端 revision 尚未追赶完成时，等待本地更新后再开始新操作。
- 同步失败时记录顶部状态、服务器 revision、修改对象和大致时间。

### 服务器维护

维护期间平台可能允许浏览但暂停写入。每次尝试拖动或编辑时，界面会提示当前修改无法自动保存，并建议保留
本地存档。可以关闭提醒，也可以选择本次打开文件不再提醒；重新打开文件后会再次提醒。

维护期间不要假设修改已经上传。优先停止继续编辑；如任务紧急，使用平台提供的本地项目导出保留副本，待
维护结束后再按负责人安排恢复或整合。

## 14. 标注审核与范围评论

若任务包含复核，可通过“视图 -> 右侧标注审核”打开停靠面板，也可以选择“标注审核独立窗口”。

审核面板提供两类互不替代的记录：

- **确认**：说明当前 revision 的指定时间和轨道范围已经检查。
- **评论**：对当前范围留下必须填写的文字意见，时间轴上以红色显示。

基本步骤：

1. 在面板中选择确认或评论。
2. 设置当前时间范围。
3. 选择整个项目、指定轨道或其他可用审核目标。
4. 确认可填写可选备注；评论必须填写正文。
5. 点击“确认当前范围”或“评论当前范围”。
6. 在审核历史中检查新记录是否出现。

确认和评论都绑定创建时的文件 revision，不会推进标注 revision。文件继续修改后，旧审核记录仍被保留，但
会以过期状态与当前内容区分。没有审核操作入口时仍可继续普通标注，不要用修改标注正文的方式代替评论。

## 15. 导出和阶段性交付

在线自动保存负责更新服务器文件；项目 JSON 和 SRT 导出用于交换、检查或额外留档，两者不要混为一谈。

- 项目 JSON 保存完整标注、轨道结构、四声、句级分类、角色和其他研究数据。
- 逐字 SRT 主要用于交换字级时间和外部播放，不是完整项目备份。
- 导出前先等待“已同步”，确保本地界面与服务器版本一致。

除非项目负责人要求，不要把导出的旧 JSON 再作为新项目导入并覆盖当前在线文件。

## 16. 离开文件前检查

完成当次工作后，按以下顺序检查：

1. 回放刚刚修改的范围。
2. 检查句级红色未完成项。
3. 检查逐字是否漏字、重复或越出句级范围。
4. 检查动作、自定义轨和分叉归属。
5. 检查需要的四声、工尺、板眼或打点信息。
6. 检查是否留下意外重叠、极短块或错误吸附。
7. 等待顶部显示“已同步”。
8. 再返回资源管理器或关闭页面。

## 17. 常见问题

### 点击文字块后，播放头为什么没有移动？

这是正常设计。点击块用于选择；需要跳转播放时，请点击时间尺或时间轴允许定位的空白位置。

### 切换监听音轨后，波形为什么没有一起变化？

当前声音选择与分析来源独立。请在“波形/频谱设置”中选择对应音轨。

### 为什么句级字幕是红色？

该句还没有同时填写“念白/唱”和角色行当。两项完成后会显示为蓝色。

### 为什么松开块边界后位置和预览略有不同？

拖动中显示的是预览和吸附候选，松手后显示最终提交结果。若差异持续或明显，请放大时间轴重试，并记录缩放
倍率、轨道和时间位置供排查。

### 为什么不能创建新块？

先确认使用了 `Command/Ctrl + 拖拽`、目标轨道允许该块类型，并检查顶部是否处于只读、维护、远端追赶、
结构锁或同步错误状态。不要连续重复创建，以免恢复后出现重复实体。

### 为什么波形或频谱没有显示？

它们默认关闭。先在“视图”或“波形/频谱设置”中开启，再检查分析来源和任务状态。

### 同步失败时应该做什么？

停止继续修改同一对象，保留当前页面，查看界面给出的重试、冲突检查或草稿恢复入口。记录账号、文件名、
服务器 revision、修改时间和修改对象后交给项目负责人。不要通过反复刷新或重新导入旧 JSON 强行覆盖。

## 18. 快捷键速查

| 操作 | 快捷键或方式 |
| --- | --- |
| 播放/暂停 | 空格 |
| 从循环起点播放 | `P` |
| 创建块 | `Command/Ctrl + 拖拽` |
| 多选 | `Command/Ctrl + 点击` |
| 全选 | `Command/Ctrl + A` |
| 复制 | `Command/Ctrl + C` |
| 剪切 | `Command/Ctrl + X` |
| 粘贴 | `Command/Ctrl + V` |
| 删除 | `Delete` 或 `Backspace` |
| 撤销 | `Command/Ctrl + Z` |
| 重做 | `Command/Ctrl + Shift + Z` |
| 手动触发保存 | `Command/Ctrl + S` |
| 精细步进 | 播放菜单中的前后 0.1 秒或 1 帧 |

不同操作系统和浏览器可能拦截少数快捷键。快捷键无效时，使用顶部菜单或界面按钮完成相同操作。
